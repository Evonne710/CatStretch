# CatStretch 1.0.0 Release Notes

```text
CatStretch 1.0.0 🐱

This is my first macOS app, built almost entirely with AI.

I've been learning how to create with AI tools. After discovering zokuzoku's Cat Gatekeeper, I fell in love with the idea of a cat reminding you to take breaks — the original concept is really great!

So I decided to try making my own version. What makes CatStretch different is that users can upload any video with an alpha channel to block themselves from working. (Please don't upload anything weird though! 😄)

Everything in this release — the code, the visuals, and even the website — was created with the help of AI, except for the star of the app: my own cat, Meimei, whose video pops up when it's time to rest.

CatStretch is an independent project inspired by Cat Gatekeeper. It is not affiliated with or endorsed by zokuzoku.

Enjoy your breaks with Meimei! ☕️

---

这是我第一个几乎完全借助 AI 完成的 macOS 应用。

最近我在学习使用 AI 工具，偶然看到 zokuzoku 的 Cat Gatekeeper，非常喜欢“用猫咪提醒休息”这个创意，大佬的创意真的很棒！

于是决定尝试做一个自己的版本。我这个版本和大佬的不一样的是：用户可以上传任何带 Alpha 通道的视频，来阻止自己上班！不过请不要上传奇怪的东西哦！😄

这个版本里的所有内容——代码、视觉素材，甚至网站——都是在 AI 的帮助下完成的。唯一的例外是应用的主角：我自己的猫咪 Meimei，休息时会跳出她的真实视频。

CatStretch 是一个受 Cat Gatekeeper 启发的独立项目，与 zokuzoku 没有官方关联。

和 Meimei 一起好好休息吧！☕️
```
